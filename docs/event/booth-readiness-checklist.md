# Booth readiness checklist

Complete between 09:10 and 09:40 on 27 Nov, and at the dress rehearsal.

## Hardware

- [ ] Laptop on mains power; sleep and screen-lock disabled while staffed (lock when unattended)
- [ ] Monitor connected (duplicate display); resolution set; touch working if applicable
- [ ] Mouse available as a backup input
- [ ] Spare laptop with the same build (or the USB backup) on hand
- [ ] Printed tabletop card (`/print/instruction-card`, A5) placed by the screen

## Software

- [ ] `npm start` running, bound to 127.0.0.1; no errors in the terminal
- [ ] Chrome kiosk on `/kiosk`; attract screen visible
- [ ] Correct event: title footer shows "{discover} 2026"
- [ ] Approved wiTTy artwork showing (no "placeholder" labels)
- [ ] FormSG URL configured: the interest screen shows a QR (not "to be confirmed"), and scanning it opens the right form
- [ ] Sound muted (default) unless the booth wants it
- [ ] Admin login works on a separate window; passcode held by the tech lead only

## Functional run (2 minutes)

- [ ] Full game by touch; all three missions; research steps appear and can be skipped
- [ ] Results show a score and tier; Play again works
- [ ] Shift+S opens the staff panel; GovEntry reminder shows **text only**
- [ ] Staff panel shows **0 pending** after Sync now
- [ ] Leave it idle: "Still playing?" warning appears, then it returns to attract
- [ ] Admin dashboard counts include the test run (note the numbers so they can be excluded in the report)

## People

- [ ] Staff briefed on the script, the no-coaching rule, the GovEntry process and the reset procedure
- [ ] One named tech lead for sync and exports at 12:30 and 15:30
