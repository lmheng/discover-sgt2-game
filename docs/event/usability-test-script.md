# Usability test script (mobile and kiosk)

**Required before declaring the project ready.** Automated tests cover function, not comprehension.

- Participants: at least 5 public officers who have not seen the game (at least 2 on a phone, at least 3 at the kiosk set-up). Include at least one person who doesn't read Chinese, Malay or Tamil.
- Facilitator: says only "Please play this game as you would at a booth." Doesn't help unless the participant is stuck for more than 15 s.

## Observe and record (per participant)

| # | Task / question | Success? | Time | Notes |
|---|---|---|---|---|
| 1 | Starts the game from attract or title without help | | | |
| 2 | Understands Rush within the first 2 cards (drag or tap) | | | |
| 3 | Completes Detective without knowing the language | | | |
| 4 | Discovers the human-review step in Launch (or learns it from the warning) | | | |
| 5 | Recognises research steps as "not scored" | | | |
| 6 | Finds Skip if they want it | | | |
| 7 | Total time (target 90–120 s) | | | |
| 8 | Any text too small or clipped (phone) | | | |
| 9 | Any confusing wording | | | |

## Debrief questions (1 minute)

1. "What do you think SG Translate Together / Polyglot / the API are each for?" (checks learning)
2. "Was anything unclear or frustrating?"
3. "Did any question feel like it was pushing you toward an answer?" (checks bias)

## Pass criteria

- At least 4 of 5 participants complete all three missions unaided.
- Median total time ≤ 130 s.
- No participant reports feeling pushed in the research steps.
- Mobile: no clipped controls at 360–430 px width.

Tune the mission durations in the event config if needed. No code change is required.
